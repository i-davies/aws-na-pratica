Amazon Lightsail na Prática

Aplicação web completa na AWS

Esta página que você está vendo agora está hospedada no Lightsail Object Storage e sendo distribuída globalmente pela Lightsail CDN. Ela faz parte de um projeto completo que inclui API, banco de dados e hospedagem estática.

O que construímos nesta aula

Uma aplicação web moderna e completa usando os recursos do Amazon Lightsail:

Instância Linux

Amazon Linux 2023 rodando uma API REST em FastAPI (Python) na porta 8000

Banco PostgreSQL

Managed Database com backups automáticos, alta disponibilidade e conexão segura via TLS. CRUD completo de tarefas (todos).

Object Storage + CDN

Hospedagem de arquivos estáticos (esta landing page) com distribuição global via CDN para baixa latência e cache automático.

Arquitetura da solução

Veja como os componentes se conectam para formar uma aplicação web completa:

Usuário
↓
Lightsail CDN
Landing page estática (você está aqui!)
↓ JavaScript fetch()
Lightsail Instance
API FastAPI (porta 8000)
↓ SQL queries
Lightsail Managed Database
PostgreSQL com TLS

Fluxo: O usuário acessa a landing page via CDN (cache global) → JavaScript faz requisições HTTP para a API → A API consulta o PostgreSQL → Dados retornam como JSON e são renderizados na tela.
